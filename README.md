# 🤖 Promptly

Promptly is a lightweight AI chatbot that enables users to interact with Google's Gemini AI using both text and image prompts. Built with HTML, CSS, and JavaScript, it provides a clean, responsive chat interface with real-time AI-generated responses.

---

## 🚀 Features

- 💬 Chat with AI using natural language
- 🖼️ Upload images and ask questions about them
- ⚡ Real-time AI-generated responses
- 🎨 Clean and responsive user interface
- ⌨️ Send messages using the Enter key or the Send button
- 🔄 Loading animation while waiting for AI responses

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Google Gemini API

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/AI-CHATBOT.git
cd AI-CHATBOT
```

### 2. Get a Gemini API Key

Create an API key from **Google AI Studio**.

### 3. Add your API key

Open `script.js` and replace:

```javascript
const API_KEY = "";
```

with

```javascript
const API_KEY = "YOUR_GEMINI_API_KEY";
```

### 4. Run the project

Simply open `index.html` in your browser, or use the **Live Server** extension in VS Code.
